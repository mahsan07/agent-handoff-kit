# Roadmap

## Phase 1: contract and local demo

- Handoff JSON schema
- Status transitions
- Artifact references
- Assumption and decision fields
- Owner and reviewer fields
- Validator CLI

## Later phases

- JSON Schema
- Reference file implementation
- SQLite adapter
- Agent SDK examples
- Visualization of handoff chains

## Release rule

Do not describe a phase as complete until the implementation, tests, documentation, and a reproducible demo all agree.
